# Phạm vi quyền năng và trung thực vận hành

## Trong ChatGPT ngay sau khi cài
- Kỹ năng soạn ý tưởng, phân tích bản thảo được gửi, lập kế hoạch, viết/biên tập/dịch, kiểm tra tính liên tục, ra báo cáo phê duyệt, chuẩn bị metadata, hướng dẫn xuất bản.
- Có thể tạo file thật nếu môi trường hội thoại hỗ trợ file; kiểm tra file tồn tại và hợp lệ trước khi đưa link tải.
- Các kỹ năng là **chỉ dẫn cho AI**, không tự cấp quyền thao tác máy, không tự khởi động app/daemon, không cài các dependency của sáu phần mềm.

## Khi có quyền Remote Desktop/IDE
- Chỉ sau khi chọn đúng máy và thư mục, kiểm tra các runtime đang có; không phá môi trường khác.
- Nếu dùng code gốc, người dùng chọn dự án và duyệt giải pháp; **không** tự cho rằng các thư mục của code nguồn đã được copy/installed vào plugin.
- Với phần mềm source code GPL/AGPL cần rà soát giấy phép trước khi phân phối hoặc deploy.

## Những bước luôn phải kiểm chứng
File writing/export, chất lượng định dạng EPUB, kết nối model, DB, RAG/vector, dashboard, browser automation, khả năng ghi/lưu, render ảnh; báo cáo theo bằng chứng chứ không theo dự định.
