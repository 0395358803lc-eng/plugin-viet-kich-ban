# Bản đồ quy trình sản xuất tác phẩm

**Luồng tiểu thuyết dài kỳ**: khởi tạo → nghiên cứu → premise → worldbook → cast → tổng cương → quyển/arc → dàn ý chương → viết → đánh giá → sửa → commit canon → backup → xuất.

**Luồng truyện ngắn**: chọn chủ đề → phân tích kỹ thuật tham khảo → emotional beats → viết cả truyện → review xuyên mạch → khử giọng công thức → đóng gói.

**Luồng nhập bản thảo**: kiểm tra file → tách chương → khôi phục bible/canon/timeline → đối chiếu chỗ chưa rõ → chốt phạm vi → lên chương mới.

**Luồng phim/video**: truyện/ý tưởng → kịch bản cảnh thoại → shot list → storyboard prompt → lời dẫn → QC tính liên tục → bàn giao sản xuất.

**Luồng tương tác**: story contract → node graph → biến/flags → nhánh và ending → kiểm thử đường đi → giữ state khi người chơi lựa chọn.

**Luồng xuất bản**: manuscript đã duyệt → metadata/nhan đề/giới thiệu → cover brief → export text/EPUB theo công cụ → kiểm định cấu trúc → bản phát hành.

Các luồng không được tự động xuất bản hoặc tự chạy background nếu không có công cụ được cấp quyền. ChatGPT có thể viết, phân tích và tạo tệp ở nơi mà môi trường hỗ trợ; dashboard Electron, công cụ Node, MongoDB và local model từ dự án nguồn không được tái tạo tự động bằng việc cài kỹ năng.
